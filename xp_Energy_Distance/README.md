You can find here the code to reproduce experiments on the Energy Distance.

- First, you can find the code to run the experiments on shapes, and on images in `run.sh`.
- Then, you can find the results of the shapes experiments in `Results_2D.ipynb` (Figure 1, E.5 and E.6).
- And you can find the results of image experiments in `Results_images.ipynb` (Figure 2, E.8 and E.9)
